# shawn-2026-creditcard

刷卡回饋管家（iOS／Android）的 GitHub Pages 網站與線上資料檔。

- `promo_status.json`：活動額滿狀態。**由私人 repo `promo-checker` 的排程寫入**（2026-10-16 起），不要手改、不要在這裡改爬蟲。
- `registrations.json`：登錄提醒清單（iOS／Android 共用）
- `config.json`／`config_android.json`：版本與跑馬燈
- `card_merchants.json`、`weekly_promos.json`：通路名單、每週優惠
- `privacy*.html`、`terms-android.html`、`support.html`：商店用頁面
